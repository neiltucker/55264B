Course Information:
55264B is a five-day, beginner-level Instructor-Led / Self-paced Python course developed in 2026 using Courseware Studio. It is a modernized successor to the earlier 55264A Introduction to Programming Using Python course authored by Neil Tucker for Microsoft Learning.

55264B is independently developed and is not presented as a current Microsoft course or Microsoft-endorsed product.

The course uses Python 3.12 and emphasizes current AI, machine learning, data-processing, API, debugging, logging, GitHub, Streamlit, and cloud-deployment workflows.

*****   Class Delivery   *****

The course is available in both Instructor-Led and Self-paced formats through Software Tutorial Services.

Instructor-Led materials provide the structured course content, labs, module reviews, and supporting resources used during classroom or virtual delivery.

The Self-paced eLearning version is an independent narrated learning experience created from the same approved course foundation. It includes module introductions, narrated learning scenes, knowledge checks, guided applications, labs/practice, module reviews, and learner resources.

The public GitHub repository is a companion resource. Full paid courseware and LMS packages are not distributed from the repository.

*****   Lab Environment   *****

Primary hands-on exercises use Google Colab. Later modules also use GitHub-based workflows, REST APIs, Streamlit, and cloud-hosted application deployment.

Students are responsible for any third-party accounts, API access, or software/service licensing required for optional external services used during exercises.

*****   Prerequisites   *****

- Basic command-line experience on Windows, Linux, or macOS.
- Approximately six months of programming experience in any language is recommended.
