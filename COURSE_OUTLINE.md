# 55264B Course Outline

**Introduction to Programming Using Python**  
**Duration:** 5 days  
**Modules:** 16  
**Audience level:** Beginner  
**Format:** Instructor-Led / Self-Paced

This outline summarizes the current 55264B syllabus. Full lesson content and exercises are delivered through Software Tutorial Services.

## Module 1 - Variables, Type Hinting, and Mathematical Operators

**Duration:** 150 minutes

Introduces Python 3.12 variables, core data types, static type annotations, arithmetic and comparison operators, assignment expressions, and the Google Colab runtime.

**Lab:** Variables, Type Hinting, and Mathematical Operators in Google Colab

## Module 2 - Data Collections for Feature Engineering

**Duration:** 150 minutes

Covers lists, tuples, dictionaries, advanced dictionary patterns, sets, and choosing collection types for data and machine-learning workloads.

**Lab:** Building a Feature Engineering Toolkit with Python Collections

## Module 3 - Standard Library Utilities for Data Workflows

**Duration:** 142 minutes

Explores module import patterns, interactive module discovery, `sys`, `pathlib`, `datetime`, and `os` for cross-platform data workflow automation.

**Lab:** Build an Automated File-Path Analyzer for Data Discovery

## Module 4 - Dependency Management and ML Runtimes

**Duration:** 107 minutes

Covers virtual environments, `pip`, dependency freezing and auditing, Poetry, `pyproject.toml`, and dependency management in Google Colab.

**Lab:** Auditing and Pinning ML Dependencies in Google Colab

## Module 5 - Algorithmic Branching and Decision Logic

**Duration:** 142 minutes

Covers `if` / `elif` / `else`, truthiness, Boolean operators, ternary expressions, structural pattern matching, guard clauses, and branching design.

**Lab:** Build a Threshold Routing Matrix with Branching Logic

## Module 6 - Loops and Iterative Data Pipelines

**Duration:** 142 minutes

Develops iteration skills with `for`, `while`, `enumerate()`, `zip()`, `break`, `continue`, `pass`, loop `else` clauses, and nested loops.

**Lab:** Building an Iterative Sales Data Pipeline

## Module 7 - Pythonic Comprehensions and Performance Optimization

**Duration:** 125 minutes

Uses list, dictionary, and set comprehensions, generator expressions, f-strings, and readability practices for efficient Python data transformations.

**Lab:** Pythonic Comprehensions and Generator Expressions in Google Colab

## Module 8 - File System Pipelines and Stream I/O

**Duration:** 89 minutes

Covers console I/O, `open()`, file modes, context managers, and efficient line-by-line processing of large text files.

**Lab:** Reading, Writing, and Streaming File Data in Python

## Module 9 - Data Serialization and Cloud API Interactivity

**Duration:** 150 minutes

Introduces JSON serialization and deserialization, REST concepts, HTTP methods and status codes, `urllib`, `requests`, and API authentication patterns.

**Lab:** Serializing Python Data and Calling REST APIs with JSON

## Module 10 - Modularizing Code with Functional Programming

**Duration:** 142 minutes

Covers functions, parameters and return values, variable-length arguments, LEGB scope, lambda expressions, `map()`, `filter()`, type hints, and docstrings.

**Lab:** Building a Modular Data Transformation Library

## Module 11 - Code Standards, PEP 8, and Maintainability

**Duration:** 125 minutes

Focuses on comments, docstrings, PEP 8 layout and naming conventions, import organization, Flake8, and Black.

**Lab:** Audit and Reformat a Raw Machine Learning Script with PEP 8, Black, and Flake8

## Module 12 - Debugging and Algorithmic Diagnosis

**Duration:** 71 minutes

Differentiates syntax, logic, and runtime failures and introduces `breakpoint()`, `pdb`, Google Colab debugging tools, tracebacks, and common data-processing defects.

**Lab:** Debugging and Algorithmic Diagnosis in Google Colab

## Module 13 - Exception Handling and System Logging Workflows

**Duration:** 150 minutes

Covers `try` / `except`, multiple exception handling, `else`, `finally`, custom exceptions, the Python logging module, and structured logging patterns.

**Lab:** Build an Anomaly Detection Logger with Exception Handling

## Module 14 - Machine Learning Integrations and LLM Pipelines

**Duration:** 150 minutes

Introduces secure API credentials, LLM client configuration, structured prompts, JSON-structured responses, rate limits, retry logic, and batch text-processing pipelines.

**Lab:** Build a Text Categorization Pipeline with the OpenAI API

## Module 15 - Building Python Web Applications and Cloud Deployment

**Duration:** 107 minutes

Uses Streamlit to build interactive applications, connects application code to GitHub, and introduces deployment to Streamlit Community Cloud and Hugging Face Spaces.

**Lab:** Build and Deploy a Streamlit Data Dashboard to Streamlit Community Cloud

## Module 16 - AI-Powered Web Application Capstone

**Duration:** 158 minutes

This is an optional extension module delivered at the instructor's discretion. Students integrate Python data handling, LLM API calls, Streamlit interfaces, and GitHub-based deployment into an end-to-end AI application.

**Lab:** Build and Deploy an AI-Powered Streamlit Web Application

Capstone paths include an intelligent content summarizer/sentiment analyzer or a predictive analytics application using uploaded tabular data.
