## Course overview

This 5-day course teaches Python programming with a strong emphasis on AI and machine-learning infrastructure. Students build clean Python code, work with data structures and data pipelines, consume REST APIs, integrate LLM services, apply debugging and exception-handling techniques, and deploy interactive Python applications.

Hands-on work uses Google Colab for low-configuration development. Later modules introduce GitHub-based workflows and deployment of Streamlit applications to cloud-hosted platforms.

> **AI Chat Assistant:** This course features an integrated, interactive **AI Tutor** available 24/7 directly within the courseware platform at no additional cost. Learners can ask questions in real time to explore Python 3.12 syntax, examine data pipeline architectures, investigate REST API and LLM integrations, and all other course topics.

## At course completion

Students will be able to:

- Implement Python 3.12 data structures, type annotations, and mathematical operations used in machine-learning data workflows.
- Construct data-processing pipelines using loops, comprehensions, generators, and functional programming patterns.
- Build Web API integrations, JSON serialization workflows, and authenticated LLM API connections.
- Create maintainable programs using exception handling, custom exceptions, structured logging, and PEP 8-aligned practices.
- Develop and deploy interactive Python AI web applications using Streamlit and GitHub-based deployment workflows.

## Prerequisites

- Experience performing basic command-line operations on Windows, Linux, or macOS.
